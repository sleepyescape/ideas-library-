# Как писать промпты для роликов

Короткая шпаргалка: чем отличаются инструменты, из чего состоит хороший промпт и какие слова использовать.

## 1. Два типа инструментов

| | Анимация кодом | Видеогенераторы |
|---|---|---|
| **Примеры** | Claude Motion (`/motion` в чате Claude), Claude Code + Remotion / HyperFrames / Manim / p5.js | Veo, Sora, Kling, Seedance, Runway, Luma, Hailuo |
| **Что умеет** | текст, графики, схемы, интерфейсы, иконки, логотипы, ваши картинки | «настоящее» видео: люди, природа, предметы, камера |
| **Сильные стороны** | точные цифры и надписи, бренд-цвета, любые правки, повторяемость | реализм, атмосфера, движение камеры, звук |
| **Слабые стороны** | нет живой съёмки и реальных людей | путает текст, герой «плывёт» между кадрами |
| **Длина** | сколько угодно | 5–10 с на кадр, ролик собирается из кадров |

Правило: **объяснить, показать данные, продукт, текст** — анимация кодом. **Атмосфера, люди, реклама с товаром, мультик** — видеогенератор.
Комбинируйте: кадры из генератора + титры, субтитры и графики через Remotion.

## 2. Формула промпта для анимации (Claude Motion / Remotion)

1. **Что и для кого:** «30-секундный ролик о [теме] для [аудитории / повода: all-hands, запуск, Reels]».
2. **Длина и формат:** секунды, 16:9 / 9:16 / 1:1.
3. **Структура по таймкодам:** крючок (0–2 с) → основная часть по битам → финал / CTA.
4. **Что на экране в каждом бите:** конкретные цифры, слова, элементы интерфейса.
5. **Стиль:** палитра (HEX), шрифт, характер движения (пружинисто / плавно / жёсткие склейки), фон.
6. **Звук:** темп (BPM), где удары, есть ли озвучка.
7. **Материалы:** приложите логотип (SVG), скриншоты, таблицу, документ, музыку.

Советы Anthropic для Claude Motion: укажите аудиторию или повод и длину; Motion лучше всего
объясняет **вашу собственную работу** (отчёт, график, план); всё можно поправить — слово, цифру, тайминг —
в редакторе или попросив Claude; готовое скачивается в MP4 и открывается в Adobe, Descript, HeyGen,
Higgsfield, invideo, Luma, Runway.

## 3. Формула промпта для видеогенератора

```
[план] of [объект + 2–3 детали] [действие] in [место], [время/погода].
Camera: [движение], [объектив], [глубина резкости].
Lighting: [свет], [палитра]. Style: [плёнка/стиль].
Audio: [звуки], [музыка], "[реплика]".
```

- Один кадр — одно действие. Длинную историю режьте на планы по 5–8 секунд.
- Герой: одна строка внешности, **дословно одинаковая** во всех кадрах (+ референс-картинка).
- Текст в кадре генераторы пишут плохо — титры добавляйте потом.
- Пишите на английском: генераторы понимают его лучше. Claude Motion понимает и русский.

## 4. Словарь камеры

| Русский | Английский |
|---|---|
| общий / средний / крупный / деталь | wide / medium / close-up / extreme close-up |
| наезд / отъезд | dolly-in / dolly-out (push-in / pull-back) |
| панорама влево-вправо | pan left / right |
| наклон вверх-вниз | tilt up / down |
| слежение за героем | tracking shot |
| облёт вокруг | orbit / 360° arc |
| подъём камеры | crane up / pedestal up |
| с рук | handheld |
| с дрона | aerial drone shot |
| от первого лица | POV / first-person |
| нижний / верхний ракурс | low-angle / high-angle / top-down |
| голландский угол | dutch angle |
| перевод фокуса | focus pull / rack focus |
| замедленная съёмка | slow motion (120 fps look) |
| таймлапс | timelapse |
| одним кадром | one continuous take, no cuts |

## 5. Словарь света и вида

- **Время:** golden hour, blue hour, harsh midday sun, overcast, night, neon-lit.
- **Свет:** soft key light, rim light / backlight, volumetric light (god rays), practical lights, candlelight.
- **Плёнка:** 35mm film, Super 8, VHS, anamorphic, film grain, halation, Kodak Portra.
- **Цвет:** teal and orange, pastel, monochrome, muted, high contrast, warm / cool grade.

## 6. Словарь движения (для анимации)

- **Кривые:** ease-in-out, spring with overshoot, linear (механично), bounce.
- **Переходы:** match cut, mask wipe, iris, whip pan, morph, glitch, shape zoom.
- **Ритм:** cuts on the beat, staggered entrance, hold for 3 seconds, accelerate towards the end.
- **Кинетика текста:** word by word, typewriter, split-flap, scale pop, letters stretch.

## 7. Чек-лист перед генерацией

- [ ] Понятно, для кого и где покажут (Reels, сайт, совещание).
- [ ] Есть крючок в первые 2 секунды.
- [ ] Указаны длина и формат кадра.
- [ ] В каждом бите — конкретика, а не «красивые переходы».
- [ ] Стиль описан словами (палитра, шрифт, движение), а не «сделай круто».
- [ ] Приложены материалы: логотип, данные, скриншоты, музыка.
- [ ] Для серии — зафиксирован шаблон, меняется только содержимое.
