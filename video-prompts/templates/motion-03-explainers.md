# Объяснялки и обучение

**Для:** Claude Motion · Claude Code + Remotion / HyperFrames

Сложное через простое: схемы, метафоры, пошаговые анимации. Подходит для уроков, YouTube и онбординга.

Замени всё в `[КВАДРАТНЫХ СКОБКАХ]` на своё. Остальное копируй как есть.

## Понятие через метафору

«X — это как Y»: объект превращается в метафору и обратно. `9:16` · ~30 с

```text
Create a 30-second vertical explainer: "[CONCEPT] is like [METAPHOR]". Scene 1: a big question "What is [CONCEPT]?". Scene 2: the metaphor is drawn in simple flat shapes ([METAPHOR DETAILS]). Scene 3: each part of the metaphor morphs into the real component it represents, with a label. Scene 4: one-sentence summary. Friendly flat illustration, max 8 words on screen at a time.
```

## Как это работает: 4 шага

Нумерованные шаги со стрелками и иконками. `16:9` · ~30 с

```text
A 30-second "how it works" explainer for [PROCESS]. Four numbered steps appear in sequence along a horizontal path: 1. [STEP 1], 2. [STEP 2], 3. [STEP 3], 4. [STEP 4]. Each step: an icon draws itself, a one-line label types in, an arrow animates to the next step. After step 4 the camera zooms out to show the whole flow at once. Clean, two-tone palette.
```

## Алгоритм наглядно

Сортировка, поиск, рекурсия — шаг за шагом на блоках. `16:9` · ~30 с

```text
Visualise the [ALGORITHM] algorithm in 30 seconds. Use [N] coloured bars/blocks with their values on them. Animate every comparison (highlight two elements yellow), every swap (elements arc past each other), and mark finished elements green. Show a small step counter and a pseudocode panel on the right where the current line is highlighted in sync. End with the complexity "[O(...)]" and a one-line takeaway.
```

## История на таймлайне

Горизонтальная лента лет, события выскакивают по очереди. `16:9` · ~45 с

```text
A 45-second animated history of [TOPIC]. A horizontal timeline scrolls from [START YEAR] to [END YEAR]. At each key date a marker drops and a card opens with the year, a 5-word event title and a simple icon: [EVENT 1], [EVENT 2], [EVENT 3], [EVENT 4], [EVENT 5]. The camera moves along the timeline; past events fade to grey. Final shot: the whole timeline visible and a closing line "[TAKEAWAY]".
```

## Путешествие частицы

Следуем за фотоном/каплей/клеткой через весь процесс. `16:9` · ~40 с

```text
A 40-second science explainer following [OBJECT, e.g. a photon / a drop of water / a red blood cell] on its journey through [PROCESS]. Each stage is a scene with a small label and a fact: [STAGE 1], [STAGE 2], [STAGE 3], [STAGE 4]. Show a running counter of [TIME OR DISTANCE]. Glowing particle on a dark background with soft gradients, scientific but cinematic.
```

## Математика на доске

Формулы пишутся «от руки», графики рисуются сами. `16:9` · ~30 с

```text
Make a 30-second whiteboard-style explanation of [MATH IDEA]. White background, dark marker strokes that draw on progressively like handwriting. Write the formula [FORMULA], then draw a graph/diagram that illustrates it, then highlight the key part in a second colour and show one worked example with numbers. Hand-drawn wobble on lines, no fonts that look typed.
```

## Рецепт анимацией

Пустой стакан/тарелка наполняется по ингредиентам с граммовкой. `1:1` · ~30 с

```text
A 30-second recipe motion graphic for [DISH]. Start with an empty [GLASS/PLATE]. Each ingredient enters one by one with its measurement on screen: [INGREDIENT 1 — AMOUNT], [INGREDIENT 2 — AMOUNT], [INGREDIENT 3 — AMOUNT]… Liquids pour, solids drop with a little bounce, layers stack visibly. Then the action step ([STIR / BAKE / SHAKE]) with a timer. End on the finished dish and its name. Flat, appetising colours.
```

## Что происходит за одну секунду

Счётчики событий мира за 1 секунду. `9:16` · ~20 с

```text
A 20-second vertical infographic: "What happens in one second on [EARTH / THE INTERNET / YOUR BODY]". A big 1-second clock ring sweeps slowly. Around it, counters appear one after another: [FACT 1 with number], [FACT 2], [FACT 3], [FACT 4], [FACT 5], each with a tiny icon and number rolling up. Dark background, neon accents. Note: use the numbers I give; if none are given, mark them as approximate.
```

## Миф или факт

Карточка с мифом переворачивается — на обороте правда. `9:16` · ~25 с

```text
A 25-second vertical "Myth vs Fact" about [TOPIC]. Three rounds. Each round: a red card "MYTH: [MYTH]" appears, a stamp hits it with a cross, the card flips to a green "FACT: [FACT]" with a one-line reason. Score dots fill at the top. Bold, readable type for phone screens, max 10 words per card.
```

## Онбординг для новых клиентов

Пошаговый тур по сервису с подсветкой элементов. `16:9` · ~40 с

```text
Create a 40-second onboarding walkthrough for new customers of [PRODUCT]. Use the attached screenshots. Step by step: [STEP 1], [STEP 2], [STEP 3], [STEP 4]. For each step dim the rest of the UI, spotlight the relevant element with a soft ring, show a cursor doing the action, and a caption under 8 words. A progress bar at the top shows 1/4 … 4/4. End: "You're all set" and where to get help.
```
