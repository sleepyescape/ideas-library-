# Данные, графики, отчёты

**Для:** Claude Motion · Claude Code + Remotion / HyperFrames

Цифры, которые двигаются. Прикладывай свои таблицы или пиши числа прямо в промпт: Claude должен брать только твои данные.

Замени всё в `[КВАДРАТНЫХ СКОБКАХ]` на своё. Остальное копируй как есть.

## Квартальный отчёт за 30 секунд

Итоги квартала для общей встречи: 3 цифры и вывод. `16:9` · ~30 с

```text
Turn this quarterly report into a 30-second explainer for our all-hands. Audience: the whole company, plays on a big screen. Use only the facts in the attached file / these numbers: [METRIC 1], [METRIC 2], [METRIC 3]. Structure: title card → each metric as a big number that counts up with a one-line context → one chart showing the trend → "What's next: [NEXT STEP]". Brand colours [COLOURS], no stock imagery.
```

## Гонка столбцов

Столбцы обгоняют друг друга по годам. `16:9` · ~30 с

```text
Create a 30-second bar chart race of [WHAT IS COMPARED] from [START YEAR] to [END YEAR] using this data: [PASTE CSV OR TABLE]. Top [N] bars, sorted live, bars smoothly overtake each other, values tick at the end of each bar, a large year counter in the bottom right. Each entity has a fixed colour and a label. Hold the final year for 3 seconds.
```

## Рубеж: миллион пользователей

Счётчик бежит до круглой цифры, конфетти. `9:16` · ~15 с

```text
A 15-second vertical celebration of [PRODUCT] reaching [MILESTONE NUMBER] [USERS/VISITORS/ORDERS]. A big odometer counter rolls from 0 to the number, accelerating; a line chart of growth draws behind it. When it hits the target: confetti burst, the number scales up, text "Thank you" and [SHORT MESSAGE]. Brand colour [COLOUR].
```

## Оживший график для презентации

Один график из слайда, но с движением и акцентом. `16:9` · ~12 с

```text
Add motion to this board-deck chart: [DESCRIBE OR ATTACH CHART]. 12 seconds. Axes draw first, then the data series animate in left to right, then the key point [KEY POINT, e.g. Q3 jump] gets highlighted with a callout and a short label "[INSIGHT]". Everything else dims to 40 %. Keep corporate-clean styling, no 3D effects.
```

## Сравнение двух вариантов

А против Б по пяти параметрам. `9:16` · ~20 с

```text
A 20-second vertical comparison: [OPTION A] vs [OPTION B]. Two columns with their names/logos at the top. Five rows appear one by one: [PARAMETER 1..5], each with values for A and B and a small bar showing which is better; the winner of each row glows. Final score at the bottom and a verdict line "[VERDICT]". Neutral, fair styling.
```

## Распространение по карте

Точки и линии расползаются по карте мира/страны. `16:9` · ~25 с

```text
A 25-second map animation showing how [THING] spread across [WORLD / COUNTRY] from [START] to [END]. A minimalist flat map; dots appear at [LOCATIONS] in chronological order with connecting arcs; a date counter at the top; a small legend. Colour intensity grows with [VALUE]. End with a summary number "[TOTAL]".
```

## Итоги года в стиле Wrapped

Личная статистика по слайдам: топы, минуты, сюрприз. `9:16` · ~30 с

```text
A 30-second vertical "Year Wrapped" for [PERSON/BRAND/CHANNEL]. 6 slides, ~5 s each, bold gradient backgrounds that change every slide: 1) "Your [YEAR]" intro, 2) total [MAIN NUMBER] counting up, 3) top 5 [ITEMS] list sliding in, 4) the fun fact "[FUN FACT]", 5) a personality label "You are a [LABEL]", 6) share card summary. Big playful type, sticker-like shapes.
```

## Дашборд оживает

Пустой дашборд заполняется виджетами и цифрами. `16:9` · ~20 с

```text
A 20-second reveal of a [PRODUCT] analytics dashboard. Start with an empty grid; widgets fly into place one by one: KPI tiles with numbers counting up ([KPI 1], [KPI 2], [KPI 3]), a line chart drawing itself, a donut chart filling, a table with rows sliding in. Then a cursor hovers the line chart and a tooltip shows [INSIGHT]. Dark UI, one accent colour.
```
