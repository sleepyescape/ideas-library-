# Обучение, история, наука

Уроки, история за минуту, математика и физика, «как устроено». Хорошо работают сериями.

## История за 60 секунд
- **Где:** Claude Motion, Remotion
- **Формат:** 60 с · 9:16 или 16:9
- **Теги:** history, timeline, story

```text
The history of [SUBJECT] in 60 seconds.
Five eras, 12 seconds each: [ERA 1], [ERA 2], [ERA 3], [ERA 4], [ERA 5].
Each era has its own visual style that matches the period (cave painting → manuscript → engraving → poster → digital), with the date large and one key event illustrated.
A thin timeline at the bottom fills up as we go.
End: "And now: [TODAY]".
```

## Математика рисует себя
- **Где:** Claude Code + Manim / Remotion
- **Формат:** 30 с · 16:9
- **Теги:** math, geometry, manim

```text
Visually prove/explain [MATH IDEA, e.g. why the sum of angles in a triangle is 180°] in 30 seconds.
Shapes draw themselves with chalk-like strokes; pieces move, rotate and rearrange to make the idea obvious without words.
Show the formula only at the end, building term by term.
Dark slate background, chalk-white lines, one yellow highlight, Manim-like smooth motion.
```

## Физика на доске
- **Где:** Claude Motion, Remotion
- **Формат:** 40 с · 16:9
- **Теги:** physics, whiteboard, simulation

```text
Explain [PHYSICS CONCEPT] on an animated whiteboard.
A hand-drawn diagram ([SETUP]) comes alive: objects move with correct physics, force arrows appear and change length in real time, a graph of [QUANTITY] vs time plots alongside.
Short handwritten captions appear next to each phase.
White board, blue and red markers, slight marker squeak sounds.
```

## Путешествие частицы
- **Где:** Claude Motion, Remotion
- **Формат:** 45 с · 16:9
- **Теги:** science, journey, scale

```text
Follow [A PHOTON / A DROP OF WATER / A RED BLOOD CELL / A DATA PACKET] on its journey from [START] to [END].
Camera stays locked on it; the world around it changes scale and scenery at each stage ([STAGE 1], [STAGE 2], [STAGE 3]).
A distance/time counter in the corner.
End where it arrives: "[FINAL FACT]".
Cinematic, glowing particle, rich backgrounds.
```

## Урок-слайд с анимацией
- **Где:** Claude Motion
- **Формат:** 60–90 с · 16:9
- **Теги:** lesson, school, teacher

```text
An animated lesson for [GRADE / AGE] on [TOPIC].
Structure: hook question → 3 key ideas, each with a simple animated illustration → a quick quiz question with a 3-second pause → the answer → a one-line summary.
Friendly, clear, large text; never more than 12 words on screen at once.
Classroom-poster style: bright flat colours, rounded shapes.
```

## Как устроено изнутри
- **Где:** Claude Motion, Remotion
- **Формат:** 45 с · 16:9
- **Теги:** how-it-works, exploded-view, engineering

```text
Show how [DEVICE / MACHINE, e.g. a mechanical watch / an electric car / a toilet] works inside.
Start with the object whole; it separates into an exploded view, parts labelled.
Then reassemble and run it, highlighting the flow of [ENERGY / WATER / FORCE] through the parts in colour.
Technical-illustration style: blueprint lines, isometric view, smooth rotations.
```

## Язык: слово в контексте
- **Где:** Claude Motion
- **Формат:** 20 с · 9:16
- **Теги:** language, vocabulary, learning

```text
A 20-second vertical lesson for learners of [LANGUAGE]: the word "[WORD]".
Show the word, transcription and translation; then 3 example sentences, each illustrated with a tiny animated scene, and the key word highlighted.
Finish with a mini-quiz: "How would you say: [PHRASE]?" and the answer after 3 seconds.
Cheerful flat style, consistent template for a series.
```

## Один день из жизни в прошлом
- **Где:** Veo, Sora, Kling
- **Формат:** 8 с × 6 сцен · 16:9
- **Теги:** history, reenactment, ai-video

```text
Scene [N] of 6 of "A day in the life of a [PERSON] in [PLACE], [YEAR]".
[SCENE DESCRIPTION: e.g. dawn, the baker lights the clay oven in a narrow stone street].
Historically accurate clothing, architecture and tools; natural light of the period (candles, fire, daylight).
Camera: slow handheld documentary style. Ambient sounds of the era, no music.
Keep the main character consistent: [CHARACTER DESCRIPTION].
```

## Рекурсия/идея во всех стилях
- **Где:** Claude Motion, Remotion
- **Формат:** 30 с · 16:9
- **Теги:** concept, styles, showcase

```text
Explain [CONCEPT] five times in 30 seconds, each time in a different visual style: hand-drawn sketch, Swiss poster, 8-bit pixel art, blueprint, and claymation.
The explanation is the same; only the style changes, with a quick wipe between them.
Label each style in the corner.
```

## Жизненный цикл
- **Где:** Claude Motion
- **Формат:** 30 с · 1:1
- **Теги:** cycle, biology, loop

```text
Animate the life cycle of [ORGANISM / PROCESS, e.g. a butterfly / water / a star] as a seamless loop.
Stages arranged in a circle: [STAGE 1] → [STAGE 2] → [STAGE 3] → [STAGE 4]; the camera rotates around the circle as each one transforms into the next.
Small labels, natural palette, soft lighting. The loop restarts invisibly.
```

## Что происходит за одну секунду
- **Где:** Claude Motion, Remotion
- **Формат:** 30 с · 9:16
- **Теги:** numbers, world, per-second

```text
"What happens on Earth in one second?"
A large 1-second timer is frozen while facts appear one by one: [N] babies born, [N] emails sent, [N] lightning strikes, [N] searches, [your own facts].
Each fact has a mini animated icon swarm of the right density.
At the end the timer finally ticks: 0.00 → 1.00.
```

## Шпаргалка-экзамен
- **Где:** Claude Motion
- **Формат:** 45 с · 9:16
- **Теги:** cheat-sheet, exam, revision

```text
A 45-second revision video for [EXAM / TOPIC]: the 7 things you must remember.
Each item: a big number, a keyword, a one-line rule, and a memorable visual hook (mnemonic).
Recap screen at the end shows all 7 as a cheat sheet to screenshot.
Notebook grid paper look, highlighter colours.
```
