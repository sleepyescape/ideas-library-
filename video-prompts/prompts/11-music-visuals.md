# Музыка и визуалы

Клипы, визуализаторы, обложки-анимации (Spotify Canvas), фоны для диджей-сетов.

## Аудиовизуализатор под трек
- **Где:** Claude Code + Remotion
- **Формат:** длина трека · 16:9 или 1:1
- **Теги:** visualizer, audio-reactive, music

```text
Build an audio-reactive visualizer for [TRACK FILE].
Analyse the audio: kick drives a central shape's scale, hi-hats spawn small particles, bass moves a slow background gradient.
In the centre: the cover art [ATTACH COVER] in a circle that rotates slowly.
Artist name and track title in the lower third. Colours taken from the cover.
```

## Spotify Canvas (луп 8 с)
- **Где:** Claude Motion, Veo, Kling
- **Формат:** 8 с · 9:16 (бесшовный)
- **Теги:** spotify-canvas, loop, cover

```text
An 8-second seamless vertical loop for Spotify Canvas, based on the cover art [ATTACH COVER] of "[TRACK]" by [ARTIST].
Subtle motion only: [WHAT MOVES, e.g. the sky drifts, hair moves, light flickers].
No text, no hard cuts. Leave the lower third calm (the app overlays UI there). The last frame must match the first.
```

## Клип из одного промпта
- **Где:** Claude Code + Remotion
- **Формат:** 2–3 мин · 16:9
- **Теги:** music-video, generative, full

```text
Make a full music video for [TRACK FILE] entirely in code.
Split the song into sections (intro, verses, chorus, bridge, outro) by energy; give each section its own visual world built from [THEME].
Cuts land on downbeats; the chorus brings the biggest, brightest visuals; the bridge strips everything back to one element.
Lyrics optional as kinetic type: [LYRICS].
```

## Машина, которая играет музыку
- **Где:** Claude Code + Remotion, Three.js
- **Формат:** 30 с · 16:9
- **Теги:** music-machine, physics, satisfying

```text
A Rube Goldberg-style machine that plays [MELODY / TRACK]: marbles roll down rails and hit xylophone bars, drums and bells exactly on the notes.
Generate the MIDI timing first, then build the track layout so physics matches the music.
Clean 3D, wood and brass materials, camera following the marbles.
```
