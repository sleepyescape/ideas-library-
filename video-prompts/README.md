# Библиотека промптов для роликов

98 готовых шаблонов для генерации видео, плюс конструктор: крючки, камера, стили, свет и звук.
Все шаблоны написаны с нуля для этой библиотеки. Подставь своё в `[СКОБКИ]` и вставь в нужный инструмент.

## С чего начать

1. Выбери, **чем** делаешь ролик:
   - **Код-анимация** (Claude Motion, Claude Code + Remotion / HyperFrames): текст, графики, интерфейсы, инфографика, логотипы. Всё чётко, текст читается, цифры твои.
   - **Генераторы видео** (Veo, Sora, Kling, Runway, Seedance и др.): живые кадры, персонажи, реклама, атмосфера.
2. Открой категорию ниже, скопируй шаблон и замени `[СКОБКИ]`.
3. Не хватает деталей? Добери их в [конструкторе](building-blocks.md).
4. Промпты на английском: генераторы понимают его лучше. Claude можно писать и по-русски.

## Про Claude Motion

Claude Motion — функция Claude (бета, тарифы Team и Enterprise): анимация строится кодом, а не генератором видео,
поэтому реалистичных людей и съёмки она не делает. Запуск: в чате нажать **Output → Motion** или просто попросить анимацию;
готовое экспортируется в MP4. Совет из справки: укажи, кто смотрит, где будет играть и примерную длину, и приложи свои данные.
Подробнее: [справка Anthropic](https://support.claude.com/en/articles/17454997-get-started-with-claude-motion).
Без этого тарифа те же шаблоны работают в Claude Code с Remotion или HyperFrames.
