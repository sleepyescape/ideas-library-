# ideas-library

Reference library for generations.

## Collections

- [`video-prompts/`](video-prompts) — 180 шаблонов промптов для роликов в 15 разделах (объяснялки, запуски, реклама, Reels, типографика, графики, логотипы, обучение, мультики, кинокадры, музыка, личное, бизнес, фоны, стили) + [шпаргалка](video-prompts/guide.md) по промптам для Claude Motion и видеогенераторов.
- [`subframe-motion/`](subframe-motion) — 309 React animation examples from [subframe.com/motion](https://www.subframe.com/motion): source code, previews, motion/look descriptions and tags.
- [`fliki-claude-motion-graphics/`](fliki-claude-motion-graphics) — 83 motion graphics videos made with Claude, from [fliki.ai](https://fliki.ai/features/claude-motion-graphics): the creators' exact prompts, short briefs, categories and links to the original posts.

## Plugins

- [`plugins/`](plugins) — плагины Claude Code, которые подключаются автоматически при открытии репозитория, без установки на ПК. Как добавить свой — в [`plugins/README.md`](plugins/README.md).
