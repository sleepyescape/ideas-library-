# Subframe Motion — reference library

Snapshot of [subframe.com/motion](https://www.subframe.com/motion) (309 open-source React animation examples), collected as references for generations.

Each folder in [`examples/`](examples) contains:

- `README.md` — description, look, motion, how to adapt, taxonomy
- `component.tsx` — full source of the example
- `meta.json` — raw metadata (tags, techniques, feel, triggers, …)
- `preview.webp` — preview image

Shared images used by gallery examples live in [`assets/`](assets). Machine-readable index: [`catalog.json`](catalog.json).

Licensing: each example keeps the license of its source (see the **Source** line in its README and the header of `component.tsx`). Subframe originals are MIT.
