# Яндекс Спейс — динамичная реклама с 3D (варианты)

Исходники: живые клипы Hailuo (коридор, реакция, улица, кафе) + 3D, которое рендерится кодом
(three.js через Playwright → кадры → ffmpeg). Проверено: 3D-рендер в облаке работает.
Формат 16:9, 1920×1080, 25–30 сек, монтаж под бит (~120 BPM → смена каждые 0,5 с).

Референс с YouTube (gG569hZfw1g) не открылся: сеть сессии не пускает на youtube.com.
Нужен файл ролика или скрины, чтобы подстроить стиль под него.

## Вариант A. «Город, который дышит» (3D-диорама Казани)
| Время | Кадр | Чем делаем |
|---|---|---|
| 0–3 c | Коридор, пуш «Пары не будет» (готовый клип 1) | Hailuo + наш монтаж |
| 3–4 c | Стоп-кадр, экран «втягивается» в телефон Камили, камера ныряет в экран | 3D-переход |
| 4–10 c | Пролёт над low-poly Казанью в стиле карты прототипа: озеро Кабан, улицы. Крыши кафе снимаются, внутри столики загораются зелёным/серым в ритм, пины падают с отскоком, счётчики «свободно 5» тикают | 3D |
| 10–14 c | Камера влетает в «Бульвар Кофе»: зал собирается из плиток, столик №5 поднимается и вспыхивает жёлтым, штамп «Забронировано» | 3D |
| 14–18 c | 3D-телефон крутится, на экране настоящие скриншоты: карта → схема зала → «Забронировано!» | 3D + скрины прототипа |
| 18–24 c | Улица и кафе (клипы 4–5), быстрые склейки | Hailuo |
| 24–28 c | Пэкшот: логотип, вокруг по орбите летают столики, слоган | 3D |

## Вариант B. «Занято → Свободно» (кинетическая типографика + 3D)
Буквы как объёмные таблички. «ЗАНЯТО» прилетает трижды и разбивается, на бит переворачивается
табличка «СВОБОДНО». Между ударами — 0,5-секундные вставки живых кадров (реакция Эмиля, Аля с
телефоном). Цифры «0 звонков · 10 секунд · 1 столик» выбиваются как на табло. Самый «тиктоковый».

## Вариант C. «Две ветки» (3D-метро из флаера)
Шарик-пассажир на станции «Пару отменили». Сплит-экран: по красной ветке шарик петляет
«Позвонить → Не дозвониться → Мест нет → Домой ни с чем», таймер 40:00. По жёлтой — две
станции и прилёт к «Столик у окна» за 0:10. Камера летает вдоль путей. Связан с флаером №12.

## Вариант D. «Разбитый стоп-кадр»
Живой кадр коридора замирает, рассыпается на 3D-плитки, плитки на лету пересобираются в схему
зала кафе, где столики светятся. Обратный переход: схема снова становится живым кадром кафе.
Самый «вау», но сложнее всего.

## Рекомендация
A как основа + удары из B (табло цифр, «Свободно») в середине. Живых клипов достаточно 3–4.
