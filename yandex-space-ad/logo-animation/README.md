# Анимация логотипов Яндекс Спейс (60 fps, 35,6 с)

- `yandex-space-logo-anim-60fps.mp4` — готовый ролик 1920×1080, 60 fps, с треком.
- `anim.html` — сцена: всё считается от времени в `seek(t)`; `beats.json` — доли трека (≈99 BPM).
- Рендер: `node render.js <папка> 0 2138 3` (3 подкадра на кадр), затем
  `ffmpeg -framerate 180 -i frames/%06d.jpg -i track.mp3 -filter_complex "tmix=frames=3,select='eq(mod(n\,3)\,2)',setpts=N/60/TB" -r 60 ...`

Тайминг: 0–8,7 с логотипы-карточки по долям → 9,3 с «Яндекс» — вылет оригинального логотипа →
10,3 с «Спейс» → карусель → ленты → сетка с переворотом → воронка → 34,4 с финальный удар.
