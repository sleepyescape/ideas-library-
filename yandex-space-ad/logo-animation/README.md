# Интро с логотипами Яндекс Спейс (60 fps, 12,8 с)

- `yandex-space-logo-intro-60fps.mp4` — готовый кусок 1920×1080, 60 fps, 0–12,8 с трека.
- `anim-36s-variant.html` — первый вариант на весь трек (не используется).
- `anim.html` — сцена: всё считается от времени в `seek(t)`; `beats.json` — доли трека (≈99 BPM).
- Рендер: `node render.js <папка> 0 768 3` (3 подкадра на кадр), затем
  `ffmpeg -framerate 180 -i frames/%06d.jpg -i track.mp3 -filter_complex "tmix=frames=3,select='eq(mod(n\,3)\,2)',setpts=N/60/TB" -r 60 ...`

Тайминг: 0–9,3 с логотипы-карточки по долям, сетка, две волны переворота → 9,3–9,8 всё затягивает в центр →
9,8–10,5 пауза в треке: жёлтый круг «заряжается», кольца сходятся → 10,57 «Яндекс Спейс»: вылет оригинального
логотипа, ударная волна, взрыв карточек → 10,8 «Яндекс» по буквам → 11,19 «Спейс» → держим до 12,8.
