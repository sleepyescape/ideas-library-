# ideas-library

Библиотека референсов для генераций + маркетплейс плагинов Claude Code.
Владелец пишет по-русски, часто с телефона — отвечай по-русски, коротко и с готовыми шагами.

## Плагины: как добавлять по просьбе владельца

Владелец присылает ссылку, название или ролик (TikTok и т. п.) и просит «установи плагины».
Плагины должны работать без установки на ПК: подключаются через репозиторий.

1. **Найди плагин.** Если прислан ролик — вытащи кадры ffmpeg-ом (`fps=1/3`, склейка `tile=4x2`)
   и прочитай названия. Найди репозиторий на GitHub, склонируй его в scratchpad и проверь:
   есть ли `.claude-plugin/marketplace.json`, какие хуки (`hooks/hooks.json`) и какие внешние
   программы (CLI, pip/npm) нужны.
2. **Подключи правильным способом:**
   - **У плагина есть свой маркетплейс** (большинство чужих плагинов) — НЕ копируй его.
     Добавь в `.claude/settings.json` маркетплейс в `extraKnownMarketplaces`
     (`{"source": {"source": "github", "repo": "owner/repo"}}`) и плагин в `enabledPlugins`
     как `"<плагин>@<name из marketplace.json>": true`. Так сохраняются обновления автора.
   - **Плагин без маркетплейса или свой** — положи в `plugins/<имя>/`
     (`python3 tools/plugins.py add <папка|git-url> [--subdir ...]` или `new <имя>`).
   - **Нужна внешняя программа** — добавь её установку в `tools/session-setup.sh`
     (он работает только в облаке, `CLAUDE_CODE_REMOTE=true`; на ПК ничего не ставит).
   - **Это не плагин** (сервер, шлюз, как OmniRoute) — не ставь, опиши в `plugins/README.md`.
   - **Это инструкция без плагина** (например, гайд за Telegram-ботом) — можно написать
     свой навык в `plugins/<имя>/skills/`, не копируя чужой платный контент.
3. После правок: `python3 tools/plugins.py sync`, обнови таблицу в `plugins/README.md`.
4. Перед подключением плагинов с хуками или установкой программ — коротко скажи владельцу,
   что это сторонний код, и получи «да». Если авто-фильтр блокирует коммит/пуш, не обходи
   его: попроси переключить режим на **Accept edits** (на телефоне — в меню «+» или в заголовке
   чата) и написать «пушь».
5. Коммит в отдельную ветку → pull request в `main` → владелец сам жмёт
   **Merge pull request → Confirm merge**. Сам не сливай.

## Устройство

- `video-prompts/` — шаблоны промптов для роликов. Правишь `prompts/*.md` → `python3 tools/video_prompts.py`
  (пересобирает `catalog.json` и список в `video-prompts/README.md`).
- `plugins/` — свои плагины; `plugins/README.md` — инструкция и список всех подключённых.
- `.claude-plugin/marketplace.json` — генерируется `tools/plugins.py sync`, руками не править.
- `.claude/settings.json` — маркетплейсы, включённые плагины, хук SessionStart.
  `sync` сохраняет чужие маркетплейсы и выключенные (`false`) плагины.
- `.github/workflows/sync-plugins.yml` — пересобирает списки после загрузки в `plugins/`
  через сайт GitHub (нужно Settings → Actions → Workflow permissions → Read and write).
- Плагины подключаются только из ветки `main`.
