# Как повторить видео из каталога с Claude

Работает для любого видео из [`catalog.json`](catalog.json) (и вообще для любого ролика с анимацией).

## Коротко — скажи Claude

> Повтори анимацию из ansphare: «<название>» (ссылка на mp4 из каталога). Сделай React-компонент.

## Что Claude делает по шагам

1. **Скачать видео** — ссылка `video` из каталога:
   `curl -L -o video.mp4 "<video>"`
2. **Узнать длительность и размер:**
   `ffprobe -v quiet -print_format json -show_format -show_streams video.mp4`
3. **Нарезать кадры.** Для плавной анимации чаще, чем раз в 2 с — лучше 2–4 кадра в секунду, плюс склейка для общего вида:
   `ffmpeg -i video.mp4 -vf fps=3 -q:v 2 frames/f_%04d.jpg`
   `ffmpeg -i video.mp4 -vf "fps=2,scale=480:-1,tile=4x2" -frames:v 1 sheet.jpg`
4. **Описать увиденное:** что на экране, цвета, шрифты, что двигается, порядок, тайминг (по номеру кадра), easing, есть ли пружина/отскок, повторяется ли по кругу.
5. **Написать код:** React + TypeScript, анимации на Framer Motion (`motion`), стили Tailwind, адаптив. Компонент в `src/components/<Name>/`.
6. **Сверить:** открыть результат в браузере, снять такие же кадры и сравнить с исходными; поправить тайминг и цвета.
7. **Убрать** `video.mp4` и `frames/`.

## Варианты

- Нужен ролик, а не компонент — попроси HTML-страницу с анимацией или Remotion.
- Нужен только стиль сайта — попроси «сделай DESIGN.md по сайту <url>»: цвета, шрифты, отступы, скругления, компоненты.
