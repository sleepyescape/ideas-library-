# Видео ВКонтакте

Скрипт: `${CLAUDE_PLUGIN_ROOT}/scripts/vk_video.py`
(если переменная пуста — `plugins/vk-video/scripts/vk_video.py`).
Нужны `yt-dlp`, `ffmpeg`, `faster-whisper` (в облаке их ставит `tools/session-setup.sh`;
если чего-то нет — `python3 -m pip install --user -U yt-dlp faster-whisper`).

Длинную работу (несколько видео, ролики > 10 мин) отдай субагенту `vk-video`,
чтобы не забивать основной чат логами.

## Шаги

1. **Что смотреть.** Ссылки — как есть. «Мои видео», «закладки», «видео сообщества X»,
   «найди про …» — сначала список:
   ```bash
   python3 vk_video.py list --mine            # или --faves, --owner -123, --search "запрос"
   ```
   **Закрытое сообщество, где владелец состоит:** нужен вход (ниже). Затем
   `list --group https://vk.com/имя` (или `club123`); если ссылки нет — `groups --find "часть названия"`
   покажет сообщества аккаунта. Видео по ссылкам из такого сообщества качаются через API
   автоматически (yt-dlp без входа их не видит).
   Покажи владельцу пронумерованный список и спроси номера (если не ясно из просьбы).
2. **Расшифровка** (+ раскадровка, если нужно понять картинку):
   ```bash
   python3 vk_video.py transcribe ССЫЛКА [ССЫЛКА ...] --lang ru --frames
   ```
   Звук — в `vk-videos/`, текст — в `transcripts/` (`.txt` с таймкодами, `.srt`, `.vtt`),
   листы кадров 4×2 — `vk-videos/*_frames_NN.jpg`. Только скачать — `get` вместо `transcribe`.
3. **Посмотри кадры** (Read по картинкам) и опиши, что происходит в кадре, если владельцу
   важна картинка: надписи на экране, сцены, монтаж.
4. **Результат:** отправь `.txt` (и `.srt`, если нужны субтитры) через SendUserFile и коротко
   перескажи: о чём ролик, 3–5 пунктов. Доработки (чистый текст, конспект, перевод, спикеры) —
   как в навыке `audio-transcribe`.

Публичные видео работают без входа. Если скрипт пишет «VK не принял вход» или «нет доступа» —
значит видео закрытое, нужен вход (ниже).

## Вход в аккаунт

Пароль от ВК **никогда** не спрашивай и не принимай в чате. Если владелец прислал токен или
пароль в чат — скажи, что его стоит сменить/отозвать.

**Токен VK API (основной способ, работает с телефона):**
1. Сначала вызови `get_environment` и сделай то, что он советует для секретов. Затем вызови
   `request_credential` с `host: "api.vk.com"`, `suggested_type: "bearer"`,
   `display_name: "VK token"` — владелец увидит защищённую форму. Токен хранится в секретах
   облачного окружения, прокси сам подставляет его в запросы к api.vk.com; в репозиторий
   и в чат он не попадает.
2. Перед формой объясни владельцу, где взять токен:
   - открыть в браузере телефона (войти в ВК, нажать «Разрешить»):
     `https://oauth.vk.com/authorize?client_id=2685278&scope=video,offline&redirect_uri=https://oauth.vk.com/blank.html&display=mobile&response_type=token&revoke=1`
   - в адресной строке открывшейся страницы скопировать то, что между `access_token=` и `&`;
   - вставить в форму (не в чат).
   Предупреди честно: это вход через стороннее приложение (Kate Mobile), токен даёт доступ
   к видео аккаунта; отозвать — ВК → Настройки → Безопасность → «Приложения» / «Завершить
   другие сеансы». Если ВК перестал выдавать токен этим способом — переходи к cookies.
3. Проверь: `python3 vk_video.py auth` → «Вход выполнен: Имя Фамилия».

**Cookies (если токен не даёт файл видео):** владелец экспортирует cookies vk.com
в формате Netscape (расширение «Get cookies.txt» на ПК) и присылает файл в сессию.
Положи его в `~/.config/vk-video/cookies.txt` (не в репозиторий!) — скрипт передаст его yt-dlp.
В облаке файл живёт только до конца сессии.

На своём компьютере вместо секрета можно задать `VK_TOKEN=...` в переменных окружения.

## Ограничения

- Видео, встроенные из YouTube/других сайтов, ВК не отдаёт — скрипт скажет, откуда ролик.
- Длинные записи расшифровываются ~0.3–0.5× длины на модели `small`; запускай в фоне.
- Капча/блок ВК — подождать и повторить, не долбить запросами.
- Скачивай только то, что владелец вправе смотреть; файлы не публикуй.
