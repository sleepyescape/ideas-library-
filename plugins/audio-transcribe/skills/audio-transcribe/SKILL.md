# Расшифровка аудио

Работает локально на Whisper (faster-whisper): без API-ключей, запись никуда не отправляется.

## Шаги

1. **Найди запись.** Путь к файлу в репозитории/загрузках или ссылка http(s).
   Если файла нет — попроси прислать (или положить в репозиторий), ссылки на TikTok/YouTube
   скрипт сам не скачивает.
2. **Проверь зависимости:** `python3 -c "import faster_whisper"`. Если ошибка —
   `python3 -m pip install --user -q faster-whisper` (в облаке это делает `tools/session-setup.sh`).
   Нужен `ffmpeg` не обязательно — декодирование встроено.
3. **Запусти:**
   ```bash
   python3 "${CLAUDE_PLUGIN_ROOT}/scripts/transcribe.py" ЗАПИСЬ --out transcripts
   ```
   Если `CLAUDE_PLUGIN_ROOT` пуст — скрипт лежит в `plugins/audio-transcribe/scripts/transcribe.py`.
   Опции:
   - `--lang ru` — если язык известен (быстрее и точнее, чем автоопределение);
   - `--model` — `small` по умолчанию; `medium`/`large-v3` точнее, но медленнее; `tiny`/`base` — быстрый черновик;
   - `--translate` — сразу перевод на английский;
   - `--formats txt,srt` — только нужные форматы.
   Длинные записи (> 15 мин) запускай в фоне и предупреди, что займёт время
   (на CPU модель `small` — примерно 0.3–0.5× длины записи).
4. **Результат:** в `transcripts/` появятся `.txt` (с таймкодами), `.srt`/`.vtt` (субтитры), `.json`.
   Отправь владельцу `.txt` (и `.srt`, если нужны субтитры) через SendUserFile.
5. **Доработка по просьбе** (делай сам, без скрипта, по тексту расшифровки):
   - «чистый текст» — убрать таймкоды, слова-паразиты, расставить абзацы;
   - «кто говорит» — разметить спикеров по смыслу (Спикер 1/2), предупредив, что это догадка;
   - «конспект/выжимка» — главное, решения, задачи, цитаты с таймкодами;
   - перевод на другой язык.
   Исправляй очевидные ошибки распознавания (имена, термины), но не выдумывай то, чего нет в записи;
   неразборчивые места помечай `[неразборчиво]`.
